# Changelog

## [1.0.0] — 2026-11-16

Первый публичный релиз: проект переведён с Django 4.0 + Vue 2 на Django 5.2 LTS
с серверным рендерингом и выведен в прод на [zh-gallery.ru](https://zh-gallery.ru).

### Добавлено

- Слоистая архитектура: `selectors` (чтение) и `services` (запись), вьюхи без ORM.
- Медиа в Nextcloud по WebDAV (собственный клиент) с локальным кэшем, пережатием
  в веб-размер и вариантом оригинала для зума.
- Telegram-бот как отдельный сервис: `/random`, `/image`, `/contact`, `/about`.
- Генерация описаний работ vision-моделью и кнопка в админке.
- Превью категорий и подкатегорий из существующих работ.
- CI/CD: GitHub Actions → GHCR → SSH-деплой с ключом, ограниченным forced-command.
- Healthcheck у каждого контейнера, страница технических работ на 502/503/504.
- Аналитика Яндекс Метрики с загрузкой только после согласия на cookie.
- Юридические страницы (политика ПДн, условия) на ru/en и запись согласия.

### Изменено

- Фронтенд: Django-шаблоны + Bulma и иконки локально, нативные ES-модули вместо Vue 2.
- Аутентификация: django-allauth 65, вход через ВК и Mail.ru, письма в стиле сайта.
- Медиа-пути: `<категория>/<подкатегория>/<файл>`, команда `reorganize_media`.
- Тесты: 238 pytest-тестов, `ruff` для линта и форматирования.

### Безопасность

- Секреты только в окружении; `.env`, `.secrets/` и отчёты аудита — вне git.
- `deploy` без прав docker, единственный ключ с белым списком команд.
- Нет внешних скриптов в HTML; счётчик аналитики подключается локальным JS.
- `limit_req` на вход в админку, токен бот-API через `hmac.compare_digest`,
  белый список типов при отдаче медиа, `pip-audit` в CI.
- `manage.py check --deploy` без замечаний: HSTS, `DENY` для iframe, `nosniff`.
